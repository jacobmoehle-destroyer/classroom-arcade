Browser PC Emulator

Boot a compatible x86 PC disk image directly in this page using the open-source v86 emulator.

What this can run: DOS, FreeDOS, Windows 3.x/95/98 and some other older 32-bit operating systems, depending on the image and configuration. It is best for classic PC games. It is not a general emulator for every Windows game released before 2015: modern 3D graphics, DirectX, 64-bit software, and high system requirements are not supported reliably. v86 compatibility details ↗
Important: This page does not include an operating system, BIOS image, or commercial games. Choose a disk image you are authorized to use. Large images may be slow or exceed browser memory. Changes made inside the virtual PC are temporary unless you use a guest-OS save feature; downloading an emulator state is not the same as saving the virtual hard drive.

Game compatibility tips

  • Classic DOS games are usually the best fit for this emulator.
  • Windows 95/98 games may work if they use supported 2D graphics and older APIs, but many require drivers or hardware that v86 does not emulate.
  • Games that need 3D acceleration, modern DirectX, 64-bit Windows, online activation, or anti-cheat generally will not work here.
  • For a DOS game that will not boot as a disk image, try the site's Classic PC / MS-DOS launcher with a compatible game package.
  • Emulator code and BIOS are fetched from the public v86 host, so that host must be reachable. This page does not bypass network restrictions.
