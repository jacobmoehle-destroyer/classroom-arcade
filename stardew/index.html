Play on your iPad with Steam Link

This streams the game from a computer that is running Steam; it does not convert the Windows files into a browser game.

  1. On a computer that can run Stardew Valley, install/open Steam and make sure the game launches there.
  2. Install the official Steam Link app on your iPad.
  3. Follow Steam Link's pairing instructions to connect the iPad to the computer running Steam.
  4. Choose Stardew Valley from the streamed Steam library. A Bluetooth controller can be helpful, and touch controls depend on the game's streaming setup.
Official Steam Link setup ↗ Steam Remote Play help ↗

Steam Link requires access to a computer running Steam and a network connection. If you only have the ZIP on your iPad and no host computer, this setup will not run the game by itself.
