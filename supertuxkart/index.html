Why it isn't embedded here yet

The available WebAssembly build is experimental and runs on a separate host. It needs an initial download of about 120 MB and around 500 MB of memory, and some rendering features and networking are not supported. A link or embed here would not make a blocked service approved or guarantee it works on every iPad.

Use this page to review the project and request approval from the school or network administrator. It intentionally does not try to work around network filtering.

Browser-port technical notes

  • Game: SuperTuxKart, an existing kart-racing game—not a remake.
  • Port type: Experimental WebAssembly/Emscripten build.
  • Reported startup download: approximately 120 MB.
  • Reported memory use: approximately 500 MB.
  • Known limitations: some rendering APIs and networking are incomplete.
  • Device testing still needed: Safari/WebGL behavior, memory stability, audio, orientation, and touch controls.

License and attribution

The SuperTuxKart code is licensed under GPL version 3 or later. Any locally hosted build must preserve the applicable notices and source/license obligations.

Approval checklist

  • Ask the network administrator whether the game and its required hosting domain are allowed.
  • Confirm that use is appropriate for the setting and that external requests are acceptable.
  • Test on the actual target iPad after approval; do not assume desktop controls work on touchscreens.
  • Only self-host code and assets after checking the port's build instructions and all relevant redistribution licenses.
