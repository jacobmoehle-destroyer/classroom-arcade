# SuperTuxKart browser-port review request

Hello,

Could you review whether the open-source game SuperTuxKart and its experimental browser port may be used on the school network for an approved activity?

## What would need review
- Game: SuperTuxKart, an existing open-source kart-racing game.
- Browser technology: WebAssembly / Emscripten.
- Experimental demo host: `supertuxkart.pages.dev`.
- Estimated first download: about 120 MB.
- Reported memory use: about 500 MB.
- Known limitations: some rendering APIs and networking are incomplete.
- Project code: https://github.com/supertuxkart/stk-code
- Experimental port source: https://github.com/ading2210/stk-code
- Licensing information: https://supertuxkart.net/Licensing

The browser build is experimental and may not work reliably on school iPads. The code is GPL-3.0-or-later; game assets have separate license and attribution requirements that must be respected.

I will not attempt to evade network filtering. Please let me know whether this game and its required domain are permitted, and what conditions apply. If it is not approved, I will not use it on the school network.

Thank you.
