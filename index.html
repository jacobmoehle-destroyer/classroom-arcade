Before adding a game

  • Confirm that the game isn't suitable for students and NOTallowed by school policy.
  • Check licenses; upload copyrighted game files without permission.
  • Test Safari touch controls, audio, landscape mode, and sign-in requirements.
  • Ask school puh to approve any blocked game domains. Hosting this page on GitHub Pages does not automatically unblock other sites.
  • Prefer games with no account requirement, minimal tracking, and no external purchases.
