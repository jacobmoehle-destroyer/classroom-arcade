Before adding a game

  • Confirm that each game is age-appropriate and allowed by your school or organization.
  • Check licenses before sharing game assets or files; don't upload copyrighted game data without permission.
  • Test Safari touch controls, audio, landscape mode, and sign-in requirements.
  • Ask the appropriate administrator to approve blocked game domains. Hosting this page on GitHub Pages does not automatically unblock other sites.
  • Prefer games with no account requirement, minimal tracking, and no external purchases.
