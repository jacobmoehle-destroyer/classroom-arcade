Playing & saves

  • Controller: EmulatorJS includes on-screen controls for supported systems and controller/key-mapping settings. A connected Bluetooth controller may work if your browser exposes it.
  • Save states: after the game starts, open the EmulatorJS menu and choose Save State. Wait for the state file to finish downloading. To resume later, load the same game and choose Load State to select the saved state file. Support varies by core, so test with your game before relying on it.
  • Game saves: core support varies. Don’t assume every title or system can save the same way.
  • Privacy: favorites and recent titles are stored in this browser’s local storage. ROM data is not stored by this launcher after you close/reload it.
  • Legal files: only use game files and BIOS files you are authorized to use. This site does not provide ROM downloads or BIOS files.

The current integrated systems are based on EmulatorJS’s documented core names: gb, gba, nes, snes, n64, psx and segaMD. Actual compatibility still depends on the file, core, browser, and device.

Quick tips
  • Set the matching system first, then choose the file and press Load selected game.
  • If a ZIP does not load, try an uncompressed supported file.
  • PlayStation multi-track games may need all related files together; this simple file picker cannot always provide companion files automatically.
  • Some systems require a BIOS file that is not included here.
  • Use only game and BIOS files you have permission to use; the site does not include downloads for commercial game ROMs.

Now playing

If the emulator fails to start, check that the system matches the file, try a compatible file format, or close the player and select another game. Some BIOS files are optional, but others may be required for specific games.
