Search the site’s games, or load a compatible game file into the built-in browser emulator. Touch controls, keyboard input, and save states are provided where the emulator core supports them.

Quick note: The emulator engine loads from EmulatorJS’s public CDN, so that service must be reachable on your network. On supported touch devices, EmulatorJS provides its own on-screen controls. Use game files you are authorized to use and follow your school or network rules. N64 and PlayStation can be demanding on phones.

Choose the console first, then pick a compatible game file. The launcher passes the selected file to EmulatorJS as a temporary browser object URL; it does not commit or upload the file. File extensions are only a hint—some titles need a BIOS, special disc layout, or a different dump.

Tip: .CHD or .PBP is usually easier for a single-file PlayStation image; a .CUE may refer to other track files which browsers cannot automatically select together.

Playing & saves

  • Controller: EmulatorJS includes on-screen controls for supported systems and controller/key-mapping settings. A connected Bluetooth controller may work if your browser exposes it.
  • Save states: use the emulator’s menu to save or load a state. Its interface supports downloading a state to your device and loading a state file later.
  • Game saves: core support varies. Don’t assume every title or system can save the same way.
  • Privacy: favorites and recent titles are stored in this browser’s local storage. ROM data is not stored by this launcher after you close/reload it.
  • Legal files: only use game files and BIOS files you are authorized to use. This site does not provide ROM downloads or BIOS files.

The current integrated systems are based on EmulatorJS’s documented core names: gb, gba, nes, snes, n64, psx and segaMD. Actual compatibility still depends on the file, core, browser, and device.

Now playing

If the emulator fails to start, check that the system matches the file, try a compatible file format, or close the player and select another game. Some BIOS files are optional, but others may be required for specific games.
